# VennPlus

Five-set Venn geometry is reproduced from the open data bundled with Adrian
Dusa's R package `venn`. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
for attribution and redistribution terms.

VennPlus 是一个面向科研数据的本地交互式集合分析工具。数据只在浏览器中处理，可在固定韦恩图、面积近似的 Euler 图和多组 UpSet 图之间切换。

## 当前功能

- 2–5 组固定韦恩图；4 组使用四个等形椭圆，点击交集只查看成员，不改变出版图形
- 2–4 组 Euler 图；2–8 组 UpSet 图；6 组及以上自动使用更易读的 UpSet 图
- 自由编辑组名和成员，支持重复项清理、空行忽略和多个示例数据
- 在独立弹窗中粘贴／选择 TXT、TSV、CSV 表格（每组一列、首行为组名），预览组名与唯一成员数后确认替换；可与输入集合 TXT 下载互通，替换可撤销
- 支持撤销、重做与键盘快捷键，连续输入和标签拖动会合并为一次历史记录
- 可切换数值、百分比和组名，并用滑块或数值输入调节标签字号与加粗；界面字号与成品字号独立
- 完整名称、色条与选中标记组成可滚动色板列表；紧凑工具栏集中图形切换、缩放、侧栏开关与专注预览
- 首次打开使用三组 Venn 入门示例和 42% 不透明度的彩色填充；已有草稿保留原设置。示例菜单标注推荐模式，切换示例保留样式并支持撤销
- 可调节集合填充不透明度（0% 无填充、100% 实色）、边框粗细；支持彩色填充或仅保留色板边框。一键恢复默认样式，不改变数据、模式、交集显示数量或导出设置，可撤销
- 桌面和手机端均展示本工具的模式支持范围；添加、复制或导入集合超限时明确说明自动切换 UpSet 的原因；Euler 额外提供中文面积近似说明
- UpSet 显示当前绘制的交集数／总交集数，“查看全部交集”会展开完整结果表并清除筛选，不改变图中显示数量
- 彩色填充时可使用色板同色边框，或设置统一的自定义边框颜色
- 分组标签会根据名称长度自动外移并扩展画布，也可拖动、用方向键微调或随时重置
- Venn 与 Euler 画布支持 75%–200% 缩放和一键适应视图；UpSet 会按实际交集数自动收紧，可分别调节交集列距与集合行距，密集图保留独立横向滚动
- 点击 Venn、Euler 或 UpSet 区域后，在图下方固定展示交集成员；点击画布空白处可取消选择，并支持搜索、全选、复制及单区 TXT/CSV 下载
- 首次打开不预选区域；UpSet 高亮整列；结果区支持拖动、方向键和一键展开／收起，收起保留查询条件，未选择时保持紧凑
- “全部交集”提供完整结果、搜索、按组筛选和分页，以带名称的色标显示包含组，次级文字列出排除组，不受图形显示数量限制
- 成员查询可切换“仅这些组／至少这些组”；复制与下载共用“当前搜索结果／整个区域”范围
- 统一导出弹窗集中选择格式、成品尺寸、背景和下载；选择 PNG／TIFF 时显示 DPI，画布同步适配且不拉伸图形几何
- 导出 SVG、矢量 PDF、带物理 DPI 的 TIFF、PNG、Excel 汇总表、交集统计 CSV、每个集合一列的输入集合 TXT，以及每个非空交集一列的全部交集成员 TXT
- 可导出复现清单 JSON，记录数据哈希、设置哈希、图形参数与输出尺寸
- Euler 各阶求解统一使用包含式交集，标签仍为精确计数；画布及导出图不附带面积误差脚注或右侧交集旁注，无法由圆形区域表达的精确交集仍保留在“全部交集”结果表中。面积误差计算及完全重合、分离和嵌套回归测试保留
- UpSet 预览与导出共享画布和坐标，尺寸只改变边距、不拉伸柱形或行距；密集图预览保持可读缩放并可滚动
- PDF 内嵌 Noto Sans SC 常规／粗体字体，保留中文和矢量图形，校正非缩放线宽；字体仅在 PDF 导出时从本站加载
- 仅显示物理尺寸、DPI 和实测成品字号，不做“是否可投稿”的自动判定

Excel 文件包含 `Summary`、`Intersections`、`Members_Long` 以及每个组的独立工作表，既便于汇总统计，也便于后续筛选成员。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址。生产构建与质量检查：

```bash
npm run typecheck
npm run test:run
npm run build
```

## 输入规则

每行输入一个成员标识，例如基因名、样本编号或蛋白名称。相同组内的重复行只计算一次；集合区域按“精确归属”计算，即 `A ∩ B` 不包含同时属于 C 的成员。百分比以所有组的并集为分母。

表格导入支持引号转义、UTF-8 BOM、空单元格和不同列长，最多 8 组、20 MB；组名重复或数据列超出表头会提示错误。组名和数据在解析时去除首尾空白；单个成员不能包含换行。

CSV、Excel 和全部交集 TXT 会标注包含／排除哪些组。单区 TXT 保持每行一个成员，便于下游分析；口径以面板和文件名中的 exact/inclusive 标记为准。Euler 圆形并非总能表达全部精确区域，面积误差不会改变真实计数；需要精确数量比较时使用 UpSet 或结果表。

## 隐私

输入解析、集合计算与文件生成均在当前浏览器中完成，应用不会主动上传输入数据。
